# مەشخەڵ — المشروع الموحد

هذا مشروع Android واحد باسم **مەشخەڵ** يجمع السورس والمحتوى والتحليل من مشروعي مەشخەڵ وخيرة دون دمج هويتي الحزمتين. الحزمة النهائية: `com.meshkhal.app`.

## الهوية والواجهة

- شعار متجهي أصلي في `app/src/main/res/drawable/ic_meshkhal.xml`.
- واجهة رئيسية ببطاقات مرتبة، زخرفة هندسية مرسومة برمجيًا، وانتقالات خفيفة.
- اختيار لوحة الألوان من الإعدادات: بنفسجي ملكي/ذهبي، أزرق ياقوتي/ذهبي، أو عنبر دافئ.
- الألوان تتكيف مع وضع الهاتف الفاتح/الداكن.
- الواجهة تدعم العربية والسورانية والإنجليزية، مع RTL للغتين العربية والسورانية وLTR للإنجليزية.

## أهم المجلدات

- `app/src/main/java/com/meshkhal`: الواجهة والمستودع الموحد.
- `app/src/main/assets`: قواعد وملفات المشروع الأول.
- `app/src/main/assets/khira`: محتوى خيرة الحقيقي.
- `analysis`: أدلة REA للمشروعين.
- `docs/ai-build-spec.md`: مواصفات الميزات الحالية والمتبقية.
- `docs/implementation-status.md`: سجل حالة التنفيذ.

## التشغيل

افتح المشروع في Android Studio مع JDK 17 وAndroid SDK 35، ثم ابنِه من Android Studio. لم يُبنَ APK ضمن هذه المهمة؛ تغييرات الواجهة هنا في السورس فقط.

## قاعدة مهمة

لا تحذف الأصول، لا تستخدم بيانات Demo، ولا تعتبر المواصفات بديلًا عن تنفيذ الكود والاختبار. بعد اكتمال كل مرحلة حدّث `docs/implementation-status.md`.
