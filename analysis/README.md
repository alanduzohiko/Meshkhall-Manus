# التحليل المدمج

`rea-meshkhal/` يحتوي أدلة تحليل APK تفسيري نوور/المشروع الأول. `rea-khira/` يحتوي أدلة تحليل خيرة.apk. استخدمهما لفهم الوظائف، لكن الهوية النهائية والحزمة الوحيدة هي `com.meshkhal.app`.

المحتوى لا يُقرأ من APK وقت التشغيل؛ تم نقله إلى assets داخل المشروع. القارئ الموحد هو `MeshkhalRepository`.
