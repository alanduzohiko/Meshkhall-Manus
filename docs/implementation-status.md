## تحديث الهوية والواجهة
أضيفت في السورس هوية متجهية أصلية باسم `ic_meshkhal`، وشاشة رئيسية بطبقات وبطاقات جديدة وزخرفة هندسية مرسومة برمجياً، وانتقالات خفيفة بين التبويبات وحركة دخول للبطاقة الرئيسية. تمت إضافة اختيار 3 لوحات ألوان قابلة للحفظ: بنفسجي/ذهبي، أزرق ياقوتي/ذهبي، وعنبر/رملي؛ وتعمل مع الوضع الداكن حسب إعداد الهاتف. الواجهة تتضمن العربية والسورانية والإنجليزية.

## تحديث البناء والتحقق — 2026-10-11
- تم إنشاء Gradle Wrapper بإصدار Gradle `8.10.2`.
- تم إنشاء `.github/workflows/android.yml` لبناء `assembleDebug` وتشغيل `testDebugUnitTest` ورفع APK كـArtifact.
- فشل أول بناء بسبب عدم تطابق هدف JVM بين Java 8 وKotlin 17.
- تم إصلاح ذلك بإجبار Java وKotlin على JVM 17 في `app/build.gradle.kts`.
- نجح البناء التالي على GitHub Actions: `Android build and tests`.
- تم تنزيل `app-debug.apk` والتحقق من سلامة أرشيف APK الداخلية بنجاح؛ الحجم الناتج تقريباً 217MB بسبب قواعد البيانات والملفات المحلية المرفقة.
- لا توجد حالياً ملفات اختبار مصدرية في `app/src/test` أو `app/src/androidTest`. لذلك نجاح مهمة Gradle لا يساوي اختباراً وظيفياً شاملاً.

## ما لم يكتمل بعد
هذه النسخة ليست اكتمالاً نهائياً لكل خارطة الطريق. ما زالت تحتاج تنفيذًا واختبارًا فعليًا على هاتف: أوقات الصلاة حسب الموقع والتنبيهات، القبلة، الصوت وCache والتنزيل، النسخ الاحتياطي المشفر والاستعادة، المزامنة الاختيارية، البحث الشامل، اختبارات unit/UI/device، وتوقيع Release. راجع `docs/phone-github-guide.md` للتعليمات المناسبة للهاتف.
