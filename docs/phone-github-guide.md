# دليل بناء مەشخەڵ من هاتف Android

## الحالة الحالية

- المستودع: <https://github.com/alanduzohiko/Meshkhall-Manus>
- Workflow: `Android build and tests`
- البناء المتحقق منه: `assembleDebug` نجح على GitHub Actions.
- الاختبار المتحقق منه: مهمة `testDebugUnitTest` نجحت، لكن لا توجد حاليًا ملفات اختبار مصدرية في `app/src/test` أو `app/src/androidTest`؛ لذلك تعني النتيجة أن Gradle مرّ من المهمة، وليست تغطية اختبار وظيفي كاملة.
- اختبار محلي إضافي: تم تنزيل `app-debug.apk` والتحقق من سلامة ZIP الداخلية بنجاح.

## تنزيل APK من الهاتف

1. افتح رابط المستودع في Chrome.
2. اضغط تبويب **Actions**.
3. افتح آخر تشغيل أخضر بعنوان **Android build and tests**.
4. انزل إلى **Artifacts** واضغط `meshkhal-debug-apk`.
5. بعد التنزيل، افتح الملف المضغوط واستخرج `app-debug.apk` إن طلب الهاتف ذلك.
6. افتح APK. إذا منع Android التثبيت، فعّل السماح بالتثبيت من هذا المصدر لتطبيق الملفات أو Chrome، ثم أعد المحاولة.

هذا APK تجريبي Debug وليس نسخة Play Store موقعة بمفتاح نشر.

## إعادة البناء بعد أي تعديل

1. افتح المستودع من تطبيق GitHub أو Chrome.
2. اختر **Actions** ثم **Android build and tests**.
3. اضغط **Run workflow** ثم اختر `main` واضغط التشغيل.
4. انتظر ظهور العلامة الخضراء.
5. نزّل Artifact الجديد من صفحة التشغيل.

## حدود النسخة الحالية

السورس المرفق يحتوي على واجهة Compose ومحتوى محلي حقيقي للقرآن والأذكار وبعض الأحاديث، مع العربية والسورانية والإنجليزية والثيمات. لكنه لا ينفذ بعد جميع بنود خارطة الطريق، ومنها: حساب أوقات الصلاة حسب الموقع والتنبيهات، القبلة، الصوت والتنزيل، النسخ الاحتياطي المشفر، المزامنة، البحث الشامل، واختبارات UI/device. لا ينبغي إعلان التطبيق مكتملًا قبل تنفيذ هذه البنود واختبارها على هاتف فعلي.
